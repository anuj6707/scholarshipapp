Architecture & Machine Learning Methodology

How {{ app_name }} Works

Understanding our hybrid architecture combining hard statutory eligibility verification with high-accuracy multi-target Machine Learning classification.

1. The Hybrid Recommendation Architecture

{{ app_name }} uses a two-stage hybrid recommendation system. Many naive recommendation engines fail in financial aid because they allow probabilistic models to recommend schemes for which the student violates strict statutory rules (e.g. recommending female-exclusive scholarships to male students or Maharashtra-domicile schemes to out-of-state applicants).

Rule Engine Priority: The rule-based eligibility engine takes absolute precedence. If a student fails any hard criterion (gender, age, income ceiling, branch, domicile, disability), the scholarship is marked ineligible and excluded from the primary eligible recommendations.

Only scholarships that pass 100% of hard statutory constraints proceed to scoring and ranking.

2. Comparative Machine Learning Pipeline

Our ML system uses a rigorous comparative evaluation pipeline built with scikit-learn and XGBoost across all 32 scholarship targets:

  • Feature Engineering: Computes 16 domain-specific derived indicators from 13 raw student attributes, including academic_score, financial_need, merit_percentile, financial_hardship_score, and interaction features.
  • Model Comparison: Evaluates Logistic Regression, Random Forest, and XGBoost per scholarship target, selecting the best model based on 5-fold stratified cross-validation F1 score.
  • PCA Experiments: Tests models with and without Principal Component Analysis (95% variance retention) to determine optimal dimensionality.
  • Threshold Optimization: Per-scholarship classification thresholds are tuned on cross-validation predictions only, never on the held-out test set.
  • Preprocessing: StandardScaler for 22 numerical features and OneHotEncoder for 7 categorical attributes, fitted inside each CV fold to prevent data leakage.

3. Research & Data Limitations

Important Notice: Recommendation scores represent scholarship-match classifications in the trained model and should not be interpreted as guaranteed awards.

Official statutory eligibility is verified through the hard rule engine. Final selection and award amounts remain subject to official provider verification and college approval.
